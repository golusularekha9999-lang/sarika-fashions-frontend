SARIKA FASHIONS — UPDATED VERSION

1. Extract this ZIP.
2. Open the "sarika-fashions" folder in VS Code.
3. Open the terminal in VS Code.
4. Run:
   npm install
5. Then run:
   npm run dev
6. Open the localhost link shown in the terminal.
